Hello from Tala!

1. Какие 6 сценариев будем покрывать

Навигация с главной → File Upload
Проверяем, что с главной страницы по ссылке File Upload открывается нужная страница и заголовок h3 = "File Uploader".

Успешная загрузка TXT-файла (кнопка Choose File + Upload)
Выбираем файл, жмём Upload, проверяем:

заголовок h3 = "File Uploaded!"

блок #uploaded-files содержит именно имя файла.

Успешная загрузка PNG (любой другой тип)
То же самое, но с другим файлом — показываем, что тип файла роли не играет, главное корректный путь.

Проверка, что блок с именем файла отображается и не пустой
После загрузки проверяем, что #uploaded-files видим и текст не пустой.

Негатив: клик по Upload без выбранного файла
Ничего не выбираем, жмём Upload → попадаем на страницу с h1 = "Internal Server Error". Проверяем текст.

Загрузка через Drag&Drop-зону (скрытый input Dropzone)
Отправляем путь к файлу в скрытый input input.dz-hidden-input, Dropzone.js отрисует превью.
Проверяем, что в .dz-filename span отображается нужное имя файла.
